# avito-python-trainee
Асинхронная Python-библиотека: скачивает квадратную матрицу с удалённого сервера
и возвращает её обход по спирали против часовой стрелки, начиная с левого верхнего угла.
## Исходное задание
Тестовое задание Авито для стажёра Python:
https://github.com/avito-tech/python-trainee-assignment
## Что сделано
- Функция `async def get_matrix(url: str) -> List[int]` — интерфейс из задания.
- Загрузка по HTTP(S) асинхронно, через `httpx` (asyncio).
- Разбор текста таблицы: строки-границы `+-----+` пропускаются, числа берутся из строк с `|`.
- Обход по спирали против часовой стрелки для любой размерности NxN.
- Обработка ошибок:
  - `MatrixFetchError` — сервер вернул 4xx/5xx, не ответил за 5 секунд или соединение отклонено;
  - `MatrixParseError` — в ответе нет матрицы, попалось не число или матрица не квадратная.
- Type hints и docstrings во всех публичных функциях.
- Тесты: алгоритм, парсинг и сетевые ошибки (на фейковом сервере, без реального интернета).
## Что не сделано и почему
- **CLI и веб-сервис** — в задании требуется библиотека, а не сервис.
- **Повторные попытки (retry) и кэширование** — основной сценарий работает без них,
  это уже эксплуатационные улучшения.
- **Упаковка в pip-пакет** — в задании прямо сказано, что загружать в PyPI не требуется.
- **Поддержка неквадратных матриц** — по условию матрица всегда NxN,
  на неквадратной выдаётся понятная ошибка.
## Как запустить
Нужен Python 3.10 или новее.
```bash
python -m venv .venv
```
Активация окружения:
```bash
# Windows (PowerShell)
.\.venv\Scripts\Activate.ps1
# Lnux / macOS
source .venv/bin/activate
```
Установка зависимостей:
```bash
python -m pip install -r requirements.txt
```
## Как использовать
```python
import asyncio
from matrix_lib import get_matrix
URL = "https://raw.githubusercontent.com/avito-tech/python-trainee-assignment/main/matrix.txt"
print(asyncio.run(get_matrix(URL)))
```
Вывод:
```
[10, 50, 90, 130, 140, 150, 160, 120, 80, 40, 30, 20, 60, 100, 110, 70]
```
Обработка ошибок:
```python
from matrix_lib.exceptions import MatrixError
try:
    numbers = asyncio.run(get_matrix(URL))
except MatrixError as exc:
    print(f"Не удалось получить матрицу: {exc}")
```
## Как проверяли
1. **Автотесты:** `python -m pytest -v` — 17 тестов, все проходят.
   Покрыто: матрицы 1x1, 2x2, 3x3, 4x4, 5x5; пустая матрица; неквадратная;
   не число в ячейке; ответ 500; таймаут; отказ соединения.
2. **Живой запрос** к `matrix.txt` из задания — результат совпал с эталонным
   `TRAVERSAL` из условия (проверено командой из раздела «Как использовать»).
3. **Проверка на других размерностях:** тест `test_all_elements_present_once`
   проверяет, что для матриц от 1x1 до 9x9 каждый элемент встречается ровно один раз —
   ничего не теряется и не задваивается.
## Структура
```
matrix_lib/
    __init__.py      — экспорт get_matrix
    spiral.py        — алгоритм обхода по спирали
    fetcher.py       — загрузка по HTTP и разбор текста
    exceptions.py    — ошибки библиотеки
tests/
    test_spiral.py   — тесты алгоритма
    test_fetcher.py  — тесты разбора текста и сетевых ошибок
```
## Сложность
Обход матрицы: O(N²) по времени, O(1) дополнительной памяти помимо списка результата.
Матрица не копируется, границы сужаются на месте.
